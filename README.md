# Dashwheel-FA

پروژهٔ آماده‌سازی واژه‌نامه و منابع فارسی (ایران) برای رابط کاربری Dashwheel.

> **وضعیت:** این مخزن در حال حاضر شامل واژه‌نامه و ابزار اعتبارسنجی ترجمه است؛ APK فارسی‌شده تولید نمی‌کند و به‌تنهایی زبان برنامه را تغییر نمی‌دهد.

## ساختار
- `locales/fa-IR.json`: واژه‌نامهٔ اولیهٔ انگلیسی به فارسی و فرادادهٔ زبان.
- `locales/README.md`: راهنمای ترجمه، نگارش فارسی و راست‌چین.
- `tools/validate_locale.py`: بررسی ساختار JSON و کامل بودن ورودی‌ها.

## نکتهٔ فنی و حقوقی
فایل APK و کدهای استخراج‌شدهٔ برنامهٔ اصلی در این مخزن قرار نمی‌گیرند. این پروژه فقط داده‌های ترجمهٔ مستقل را نگه می‌دارد. ادغام ترجمه در خود Dashwheel به کد منبع مجاز یا اجازهٔ صاحب اثر و سپس اصلاح رابط کاربری برای پشتیبانی درست از RTL نیاز دارد. ترجمهٔ واژه‌ها به‌تنهایی راست‌چین بودن همهٔ صفحه‌ها را تضمین نمی‌کند.

## اعتبارسنجی
با Python 3 اجرا کنید:

```bash
python tools/validate_locale.py
```

## مشارکت
برای پیشنهاد ترجمه، کلید انگلیسی و معادل فارسی پیشنهادی را همراه با توضیح زمینهٔ نمایش آن ثبت کنید. از ترجمهٔ نام‌های تجاری، شناسه‌ها و مقادیر فنی بدون بررسی خودداری کنید.
