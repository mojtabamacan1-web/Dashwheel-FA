# Dashwheel فارسی (نسخه مستقل)

این مخزن شامل یک برنامهٔ مستقل اندرویدی با رابط فارسی و راست‌چین، الهام‌گرفته از داشبوردهای خودرو و چیدمان Dashwheel است. کد و طراحی این پروژه مستقل نوشته می‌شود و فایل APK یا کد اختصاصی برنامهٔ اصلی را بازتوزیع نمی‌کند.

## وضعیت نسخهٔ فعلی
- پوستهٔ داشبورد تیره با نمایش ساعت و کارت‌های سرعت، سوخت، مسیریابی، موسیقی، بلوتوث، سفر و تنظیمات
- رابط فارسی و پشتیبانی از چیدمان راست‌به‌چپ
- میانبرهای باز کردن نقشه، پخش‌کنندهٔ موسیقی و تنظیمات بلوتوث گوشی
- ساخت خودکار APK آزمایشی با GitHub Actions پس از هر تغییر در شاخهٔ main

**مهم:** نمایش سرعت و سوخت در این نسخه نمایشی است و هنوز به ECU، OBD-II یا حسگرهای خودرو متصل نیست. کارت سفر و برخی بخش‌ها نیز در حال حاضر جای‌نگهدار هستند. این نسخه را نباید به‌عنوان داشبورد متصل و آمادهٔ رانندگی در نظر گرفت.

## ساخت APK
با هر push به شاخهٔ `main`، گردش‌کار `.github/workflows/build-apk.yml` اجرا می‌شود. پس از موفقیت، فایل `app-debug.apk` در بخش **Actions → Build Dashwheel Persian APK → Artifacts** قرار می‌گیرد.

## فناوری
- Android native (Java)
- Gradle و Android Gradle Plugin
- حداقل Android 6.0 (API 23)
- هدف اولیه: نمایشگرهای افقی خودرو

## واژه‌نامه
واژه‌نامهٔ اولیهٔ فارسی در `locales/fa-IR.json` نگهداری می‌شود. ابزار بررسی آن در `tools/validate_locale.py` است.
